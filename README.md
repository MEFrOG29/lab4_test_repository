# lab4_test_repository

Креатор - творческое интернет пространство.

Это кроссплатформенное приложение, где любой желающий может написать собственное произведение(роман, проза, стихотворение и тд).
Главная идея - это создать уютный уголок в интернете без нейрослопа.

Первоначально через репозиторий GitHub:
1. Если с мобильного устройства то скачивание APK файла, с последующей установкой приложения.
2. Если Desktop, то либо .exe файл, либо сайт(домена пока нет).

Пользователь может выполнять роль автора, создавая произведения, либо быть читателем, уже написанных другими авторами, произведений.
Главное правило -  не использовать ИИ(например: блокируя вставку).

Приложение не имеет сложных визуальных деталей и механик, поэтому работает комфортно на любом устройстве.
Платформы Android, IOS, MacOS, Windows
